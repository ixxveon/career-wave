# Checklist: Dashboard

> 구현 완료 전 최종 점검 항목을 정의한다.
> spec.md, api-schema.md, plan.md, tasks.md, constitution.md와 일관성을 유지해야 한다.

---

## 1. Spec 검증

* [ ] User Story가 실제 화면 기능과 일치하는가?
* [ ] Acceptance Scenario가 구현 범위를 충분히 설명하는가?
* [ ] Functional Requirements가 누락 없이 작성되었는가?
* [ ] Edge Case가 정의되어 있는가?
* [ ] Success Criteria가 정의되어 있는가?

---

## 2. API Schema 검증

* [ ] API Endpoint가 정의되어 있는가?
* [ ] Request 데이터 구조가 정의되어 있는가?
* [ ] Response 데이터 구조가 정의되어 있는가?
* [ ] Error Case가 정의되어 있는가?
* [ ] API Schema와 TypeScript 타입이 일치하는가?

---

## 3. 내 정보 관리 기능 점검

* [ ] 사용자 기본 정보가 정상 표시되는가?
* [ ] 계정 상태 정보가 정상 표시되는가?
* [ ] GitHub 연동 상태가 정상 표시되는가?
* [ ] GitHub 미연동 상태 UI가 정상 동작하는가?
* [ ] 회원 정보 수정 화면이 정상 동작하는가?
* [ ] 정보 조회 실패 시 오류 메시지가 표시되는가?

---

## 4. 스크랩 공고 기능 점검

* [ ] 스크랩 공고 목록이 정상 표시되는가?
* [ ] 검색 기능이 정상 동작하는가?
* [ ] 최신순 정렬 기능이 정상 동작하는가?
* [ ] 스크랩 공고가 없을 경우 Empty State가 표시되는가?
* [ ] 검색 결과가 없을 경우 안내 메시지가 표시되는가?
* [ ] 스크랩 취소 기능이 정상 동작하는가?
* [ ] 스크랩 취소 후 목록이 갱신되는가?
* [ ] 채용공고 상세 페이지로 정상 이동하는가?

---

## 5. UI 및 사용자 경험 점검

* [ ] 로딩 상태 UI가 제공되는가?
* [ ] 오류 상태 UI가 제공되는가?
* [ ] Empty State UI가 제공되는가?
* [ ] 반응형 UI가 정상 동작하는가?
* [ ] 기존 사용자 페이지 디자인과 일관성을 유지하는가?

---

## 6. 문서 및 품질 점검

* [ ] spec.md와 구현 내용이 일치하는가?
* [ ] plan.md와 tasks.md가 일치하는가?
* [ ] constitution.md의 불변 규칙을 준수하는가?
* [ ] 사용하지 않는 코드가 제거되었는가?
* [ ] 빌드가 정상적으로 수행되는가?
* [ ] PR 생성 전 최종 검토를 완료했는가?
